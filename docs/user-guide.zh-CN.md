# Anagram 使用指南

[English](user-guide.en.md)

## 安装

**Mac 上的 Safari：** Safari 版需要 Safari 27 或更新版本。“一键”通过 WebGPU 在浏览器内
运行；分析时请保持固定的 Anagram 引擎标签页打开。完整 Safari 应用在 Apple Silicon Mac 上
也提供可选的“终端”本地引擎，与 Chrome、Firefox 一样可以在设置中切换。临时扩展只提供
浏览器内引擎，需要兼容的 GPU，不会回退到 CPU。请使用阅读器的文件选择器打开本地 PDF。
此版本尚待 Mac 真机验证；打包与验证
步骤见[开发文档](DEVELOPMENT.md#safari)。

从[最新发行页](https://github.com/CoderBak/anagram/releases)下载 **anagram-chrome-&lt;版本号&gt;.zip**
（需要 Chrome 137 或更高版本）；页面上的其他文件属于可选的本地引擎，由它的安装命令自行下载。
解压到一个准备长期保留的文件夹。打开 `chrome://extensions`，开启右上角的“开发者模式”，点击
“加载已解压的扩展程序”，选择该文件夹。之后不要移动它，位置是插件 ID 的一部分。

设置页会自动打开，列出三个编号步骤，每完成一步，编号就变成对勾：1. 设置引擎；2. Anagram 的
阅读范围（**允许所有网站**和两个 PDF 开关）；3. 将 Anagram 固定到工具栏。每次只展开一步，即第一个
未完成的步骤；点击步骤标题可以展开或收起。步骤下方的**怎么看标记**说明三种写作类别及其颜色和示例分数。

第 1 步决定 Anagram 以哪种方式运行模型。两种方式下，模型都在这台电脑上运行：

- **大多数电脑上**，模型在浏览器内运行，并立即开始下载：1.58 GB，只下载一次，从 Hugging
  Face 保存到浏览器自己的存储中；连不上 Hugging Face 时（例如在中国大陆）会自动改从镜像
  hf-mirror.com 下载。如果开启了省流量模式或磁盘空间不足，下载会等你点击
  “下载模型（1.58 GB）”。
- **在 Apple Silicon Mac，或装有 NVIDIA 显卡的 Linux 电脑上**，
  页面会先请你选择，选定之前不下载任何内容：“一键”如上在浏览器中运行；“终端”会请浏览器
  允许 Anagram 与本地引擎通信。点击**复制命令**，粘贴到终端并按回车。**查看命令**可展开命令并查看安装脚本。返回设置页面时会自动检测引擎。这条命令只会运行
  与当前插件一同构建的那份安装程序。无需管理员密码，
  也无需系统 Python。命令会把本地引擎安装到 `~/.anagram`，为当前插件注册，并在终端下载
  模型文件并显示进度（下载中断时运行 `~/.anagram/bin/anagram download` 继续）。如果 pip 或
  uv 已设置镜像（`PIP_INDEX_URL`、`UV_DEFAULT_INDEX`、`pip.conf`、`uv.toml`、
  `UV_PYTHON_INSTALL_MIRROR`），命令会从该镜像下载依赖和 Python，每个文件仍按锁定的校验值核对；
  镜像不可用时改回原始来源。
- **内存不足 4 GB**或可用磁盘空间不足的电脑会看到相应说明，不会下载任何内容；内存恰好
  4 GB 时可以运行，但评分时电脑可能会变慢。显卡支持 16 位运算时，这样的电脑，或磁盘空间
  容不下完整模型的电脑，会改用模型的轻量版本（下载 715 MB），其判断与完整模型在 99.8% 的
  文本上一致；设置页和设置中会说明这一点。

浏览器内的下载会显示进度条、百分比、已下载字节、剩余时间和速度，可以暂停、继续或取消，
并提示下载完成前保持浏览器开启（浏览器若关闭，下次 Anagram 启动时下载会接着进行）；
下载中断时页面会说明原因，点击“重试”会从中断处继续。模型通过 WebGPU 在显卡上运行；浏览器没有可用的显卡时改在
处理器上运行，速度慢得多。本地引擎会自行检测硬件、加载最合适的配置。第 1 步显示“就绪”后，
在第 2 步或按下文授权网站即可。

之后可以在设置中在两种引擎之间切换。切换到本地引擎后，浏览器内引擎的模型文件会保留，
直到你在那里删除。如果本地引擎接连意外停止，设置页和工具栏菜单会在“重试”旁提供切换到浏览器
内引擎。

开发版构建中的命令是禁用的，因为还没有与之匹配的发行版本。

Anagram 也可以在 Firefox 153 及以上版本（含 ESR）中通过 Firefox 版 ZIP 运行。Firefox 只有在 ESR、Developer Edition 和
Nightly 中、并在 `about:config` 里把 `xpinstall.signatures.required` 设为 false 时，才会长期
保留未签名的附加组件；其他版本可在 `about:debugging` 中临时加载，重启 Firefox 后失效。

## 阅读

在工具栏菜单中打开“自动分析此网站”，或在设置页或设置中允许所有网站。未授权时，工具栏菜单中的
“分析此页”会对当前页面分析一次。Google Play 图书、Libby 和 VitalSource Bookshelf 在来自
另一个地址的框架中显示书籍，开关会同时申请这两个地址；用旧版本授权过的阅读器会显示为
关闭，重新打开一次开关即可。

- 段落标签显示占比最高的类别。悬停可查看人工撰写、AI 辅助和 AI 生成的文字占比。分数为 AI 生成占比加上 AI 辅助占比的一半。展开“逐句判断”可以按阅读顺序查看每句的类别。混合段落中的下划线会标出对应句子的类别。长段落被拆成多个重叠窗口时，每个窗口分别编号。
- 当前版本分析至少 50 个词的英文正文。同一作者的相邻短段落可合并分析。
- 在**设置 → 段落标记**中，可选择仅标记 AI 生成段落，或同时标记 AI 辅助段落。

- 只对正文写作评分。[4] 或上标 ¹ 这样的引用标记、句中的公式以及 Cookie 横幅都不计入；
  作者–年份式引用会保留。网站用“查看更多”截断的帖子，展开后才会读取。浏览器翻译过的
  页面会暂停分析，直到显示原文；翻译插件添加的译文会被跳过。评论页上每条用户评论单独评分，
  从不与其他评论合并，评论者的名字、星级、日期和“有用”一行都不计入。
- 框架中的文字在 Anagram 可以读取该框架时也会被读取，包括 EPUB 阅读器的章节。它们的标签
  显示在框架内；工具栏菜单的计数和列表只涵盖页面本身。
- 如需将 Anagram 固定到地址栏旁，请按照初次设置中适用于你所用浏览器的步骤操作。
- 打开工具栏菜单可查看当前页面的存疑段落。点击段落可跳转到原文，也可以选择“重新扫描”再次读取本页。
  展开**评分明细**可查看各类判断的段落数和评分覆盖情况。“自动分析此网站”会记住你的选择。
  要选择哪些段落显示评分标签，请前往设置中的**段落标记**。工具栏图标的角标显示存疑段落数。
- 选中文字后右键可单独评分。Alt+Shift+P 显示或隐藏当前页的标记，Alt+Shift+L 打开工具栏菜单，
  Alt+Shift+J 和 K 在被标记段落间跳转。
- PDF 可以从工具栏菜单（“在 Anagram 中阅读”）或链接右键菜单在 Anagram 阅读器中打开；工具栏
  菜单底部的**打开 PDF…**打开空的阅读器，**分析文本**接受至少 50 个词的英文文本，以空行分段。
  顶部显示全文判断，展开**评分明细**可查看各类别的占比。如果同一段中的句子有不同判断，每个带下划线的句子都使用其类别的颜色。可以在设置的**段落标记**中选择显示哪些下划线。
  可以在阅读器中选择本机文件，也可以把文件拖入页面。用**打开**切换文件，用**保存**按当前文件名下载 PDF。
  窗口较窄时，部分操作会移入阅读器的**工具**菜单。若要自动打开本机 PDF 链接，请在初始设置页或设置中启用**本机上的 PDF**，并开启 Chrome 在
  `chrome://extensions` 扩展详情页中的“允许访问文件网址”，这一项任何扩展都无法替你开启：它关闭时，
  打开这个开关会带你到那个页面。阅读器会在后台读取整篇文档，从附近的页面开始，所以滚动到某一页时它的标签
  已经准备好；占用多少算力取决于这台电脑打分的速度，较慢的电脑只读当前页附近，直到你在工具栏菜单中
  选择**读取全文**（可在设置的 PDF 部分关闭）。最先出现的标签来自对各页的快速读取；片刻之后，Zotero 的文档引擎理清了段落，
  并排除了图注、脚注和参考文献，标签随之按这些段落重新绘制。2500 页以内的文档会整篇理清段落；
  内存 4 GB 的电脑上超过 600 页、浏览器不提供内存大小时（Firefox、Safari）超过 300 页，工具栏菜单
  会先提供**读取全文**，选择之前每一页在翻到时用快速读取。如果扫描件只有图片，请打开经过文字识别（OCR）处理的副本。超过 2500 页、无法使用结构分析或已关闭结构分析时，可选择**读取全文**，用快速读取分析尚未翻到的页面。菜单会显示无法读取的页数，并提供重试选项。标签紧跟在段落最后一行之后，只有那一行排满时才放到页边。阅读器工具栏中的
  **Anagram** 按钮打开工具栏菜单，菜单中的报告涵盖目前读过的所有页面（包括已经翻过去的），并显示
  已读页数；点击列表中的段落会回到它所在的页。浏览器不允许打开菜单时，这个按钮会改为读取文档。刷新显示着文档的阅读器标签页时，文档会保留，并从来源重新读取。
  在 Google 文档中，点击工具栏菜单中的“分析文档”即可进入阅读视图；工具栏菜单也会提供
  “退出阅读模式”或“返回编辑器”。

## 设置

工具栏菜单中的**设置**打开设置页面。目录可跳转到各部分。在较窄的窗口中，点击“跳转到”即可打开目录。更改会自动保存。

- **网站**控制网站访问权限、自动扫描和各站点的规则。
- **PDF**控制自动打开、后台阅读和本机文件访问权限。
- **段落标记**控制标记哪些评分，以及哪些段落显示评分标签或下划线。
- **阅读记录**可选择记录哪些内容以及保留多久。默认不记录。
- **已保存的评分**默认仅保存在内存中。选择保留 30 天，重启后也可复用网页评分。分析文本的评分始终只保存在内存中。
- **引擎与模型**显示当前引擎和检测模型。点击“管理”可切换引擎或更改模型卸载时间，点击“检查模型”可查看检测模型版本。本地引擎还支持更新、停止和卸载。

引擎在五分钟没有工作后卸载模型，需要时自动重新加载。页脚的**源代码**链接打开你正在运行的
这一版本的代码。

## 统计

Anagram 可以记录你读到的内容中有多少像是 AI 生成的。默认关闭，直到你在设置的“阅读记录”中选择
要保存的内容（菜单下方写明所选项保存什么），或在统计页面上选择：

- **每日合计**：每天读了多少词、这些内容从人工撰写到 AI 生成如何分布，以及读的是哪类页面
  （信息流、文章、论坛、文档、其他）。
- **每日合计和站点**：同上，另记录每个站点在当天所占的部分。
- **每个页面**：同上，另记录你读过的每个页面：地址、标题、当天首次阅读的时间和停留时长。这相当于
  一份阅读记录。
- **每个段落**：每次访问和你读过的每个段落：长度、判断、在屏幕上停留多久，以及文本的加盐哈希，
  用来识别重复阅读。不含地址，不含文本。
- **研究**：每次访问、每个段落和每次滚动，精确到 0.1 秒；记录域名而非地址，不记录文本：阅读研究
  所需的内容。
- **完整阅读轨迹**，可选是否包含文本：一切内容，精确到毫秒，包括指针轨迹。

旧版本中逐项选择的设置显示为**自定义**。设置会在菜单下方提醒你哪些内容可能被使用此浏览器配置的
其他人看到。展开**保留期限**可调整详细事件（7、30 或 90 天）、段落和访问记录（30、90 或 365 天）及每日汇总（一年或直到清除）的保留时间。改为保存更少的内容时，会询问是否删除新设置不会保存的已有记录；除非你选择删除，
它们会保留。

无论怎么选择，都绝不保存：无痕窗口、你关闭了 Anagram 的网站或“分析文本”中的内容；你输入的
内容；你选中或复制的内容。

段落有部分在窗口中间停留一秒即算读过，每次访问只计一次，无论回看多少次。显示的占比按期望词数
计算：模型拿不准的段落会部分计入两边。只保存每日汇总时，也可以切换主要占比指标，或按段落标记、最可能的判断计算占比。保存了段落时，统计页面上的**计算方式**可以换一种方式
计算：换一个停留时间、按段落显示了多少、只计焦点窗口、每天或只计一次、按标签词或最可能的判断、
按段落数或按时间。如果部分历史只有汇总数据，页面会显示新规则未计入的原始词数。

统计页面默认显示最近 7 天，工具栏中的“今天”链接直接打开当天。点击日期范围可以选择整月或自定义范围。
**阅读活动**显示已评分总量和每日数量。选择**占比**，可以比较阅读量不同的日期。点击柱形图或表格中的日期即可单独查看当天，选择**返回原时段**可恢复之前的日期范围。
默认指标是已评分阅读内容中 AI 生成的预计占比。在统计规则中可选择同时计入 AI 辅助与 AI 生成的内容。包含旧版记录的日期还可查看重度编辑指标。
**判断分布**显示所选时段的各类占比，展开**评分明细**可以查看覆盖情况和跳过的内容。
**阅读明细**按已记录的内容提供网站、页面类型、页面或访问标签。点击网站会筛选整份报告，点击**显示全部**可取消筛选。
在**访问**中展开**访问详情**，可查看本次记录中页面显示到的最深位置，以及有多少段落出现过或多次出现。若保留了详细事件，展开**阅读时间线**可查看段落出现的时段和滚动位置。选中某个网站后，导出默认仅包含该网站。要包含其他网站，可在导出窗口选择**全部网站**。**导出…**会把这段时间的统计保存为文件，不会比已保存的更细，
每次导出默认排除段落原文和摘录，即使已记录这些内容，也需要为这份文件单独选择。每类内容按你选择的方式保存（也可以逐项选择，地址和标题可以存为加盐哈希），格式为 JSON 或打包为
zip 的 CSV 表格，保存前会先展示文件内容。文件中的编号和哈希默认为此文件专用，除非你选择让它们在每个文件中相同
（收集你多份文件的研究会要求这样做）。Anagram 从不上传它。文件格式见
[statistics.md](statistics.md)（英文）。**清除统计**会删除全部记录。

## 更新与卸载

浏览器准备好扩展更新后，在安装引导页或设置页顶部点击**应用扩展更新**。如果使用解压安装的 Chrome 扩展，把新文件覆盖到同一文件夹，然后在 `chrome://extensions` 点击“重新加载”。
本地引擎版本较旧时，设置页会显示已安装的版本和目标版本。点击**更新引擎**，重新连接后即可看到更新后的版本。移除插件会一并删除浏览器内引擎的模型文件。

设置中的**卸载**会删除引擎、模型文件、浏览器注册，然后移除插件。只在 Chrome 中移除插件
会把引擎留在磁盘上；重新安装插件即可回到卸载入口，或运行
`~/.anagram/bin/anagram uninstall`。Windows 上，在命令提示符（cmd）中运行：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Anagram\app\maintenance.ps1" -Operation uninstall -ComponentHome "%LOCALAPPDATA%\Anagram"
```

卸载中途停下（例如某个文件正被占用）时，同一条命令可以把它做完。`~/.anagram`（Windows 上是
`%LOCALAPPDATA%\Anagram`）只用于 Anagram：卸载会删除其中的所有内容。

## 隐私

无论哪种引擎，评分都在本机完成，从不在服务器上评分。引擎只在下载模型时联网，本地引擎还会在更新时联网。打开在线 PDF 或 Google Doc 会从来源
重新读取该文档。开启阅读统计后，统计只保存在这个浏览器配置文件中。完整说明见 [PRIVACY.md](../PRIVACY.md)。
