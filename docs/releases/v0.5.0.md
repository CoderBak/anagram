# Anagram 0.5.0 — Mac test release

用于在其他 **Apple Silicon Mac（M1/M2/M3/M4 等，macOS 14+）** 上测试。当前锁定的运行库不支持 Intel Mac。本轮在 Mac 本机验证；没有启动 GitHub Actions，也没有执行 Windows / Linux 实机验证。

## 安装

1. 下载本页 Assets 中的 **`anagram-chrome-0.5.0.zip`**，解压到准备长期保留的文件夹。不要下载 GitHub 自动生成的 Source code ZIP 来安装插件。
2. 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
3. 首次设置页会给出绑定当前插件 ID 的安装命令。复制到终端运行一次；无需管理员权限，也无需自己安装 Python 或 Xcode。
4. 回到设置页，等待设备检测、推荐模型下载和性能比较，然后选择配置。推荐模型文件通常约 **1.43 GB**；Python、运行库和临时空间另计。额外比较模型按需下载。
5. 使用“分析此页”，或只给希望自动分析的网站授权。日常启动和管理都在插件内；浏览器重启后会复用已保存的设备选择。

已有开发版用户：在原解压目录替换插件文件并重新加载，然后按设置页更新本地组件。保留原目录可避免开发版插件 ID 改变。卸载时先在设置中选择“完整卸载 Anagram”；只删除浏览器插件会留下模型和本地组件。**`~/.anagram` 是专用组件目录，完整卸载会删除其中的所有内容，请勿把个人文件放入其中。**

## 本次更新

- 完整 PDF.js 查看器：搜索、缩略图、目录、缩放旋转、密码、打印与下载；可选自动接管已授权 PDF，支持本地文件选择和拖入。
- 按设备下载推荐模型；基准测试隔离进程，明确内存与采样口径，保留手动选择和重新测试。
- 修复消息授权、权限撤销、规范化、缓存清除 / 过期及模型来源一致性；增加粘贴文本分析和更明确的隐私控制。
- 加固安装回滚、运行配置、下载续传和维护锁；将已知依赖缓存放入组件目录。Mac 使用预编译语言识别依赖，安装时禁止源码编译。

## 测试范围与已知限制

已完成本机安装器、原生组件、类型 / 单元检查，以及隔离 Chrome / Firefox 的 PDF 和安装界面测试。最终 ZIP 检查权限、CSP 与本地执行资源。测试详情见源码中的审计记录；这不是全面安全认证或模型准确率评估。

- “跟随阅读、快速滚动跳过、有界抽样”的调度策略已列为下一轮 TODO，本版尚未实现。PDF 分析仍限已渲染的前 300 页，整份文档可以阅读；刷新后可能需重新打开文件。
- Firefox ZIP 未签名，仅用于开发者临时加载，重启后需重新加载。
- 文件系统审计还记录了卸载中断后的恢复、不同自定义组件目录同时注册等边缘情况。本地组件有当前用户的 OS 权限，不是文件系统沙箱。
- Windows / Linux 附件来自同一源码，但本轮未在这些系统上验证；请优先测试上述 Mac / Chrome 路径。

## English

This release is intended for testing on **Apple Silicon Macs with macOS 14 or later**. Extract `anagram-chrome-0.5.0.zip` into a permanent directory, enable Developer mode at `chrome://extensions`, and choose **Load unpacked**. Run the first-run page's exact installation command once, then return to the extension for device detection, model downloads, benchmarking and selection. No administrator access, existing Python installation or Xcode is required. Normal operation is browser-managed.

The release includes the complete packaged PDF.js viewer, device-aware model setup, cache / authorization fixes and filesystem hardening. The viewport-aware scheduling proposal remains a future TODO. This release was validated locally on Mac; no GitHub CI or Windows / Linux execution was performed. Firefox's ZIP is unsigned and temporary-install only.

## Model attribution and checksums

Based on [Pangram's EditLens RoBERTa-large](https://huggingface.co/pangram/editlens_roberta-large), with converted artifacts in [CoderBak/editlens_roberta_modelkit](https://huggingface.co/CoderBak/editlens_roberta_modelkit). Model artifacts retain **CC BY-NC-SA 4.0**, including attribution, noncommercial and share-alike requirements. This release does not change the Hugging Face model weights.

Each download has a matching SHA-256 checksum. Checksums detect damaged or mismatched downloads; they are not an independent publisher signature.
